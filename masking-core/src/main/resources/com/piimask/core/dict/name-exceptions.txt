# 기본 예외 사전: 이름 규칙("성씨 + 1~2음절 + 호칭·서술")에 걸리지만 이름이 아닌 말. 한 줄에 하나, 2자 이상.
# 문장에서 이 단어가 나온 자리 안에 완전히 들어가는 규칙 이름 스팬만 버린다(이름 유형에만 적용, 번호에는 적용하지 않음).
# "*점" 처럼 * 로 시작하면 "이 글자로 끝나는 규칙 이름 스팬"을 버린다(지점명).
# 실제 이름일 수 있는 말(지연, 하루, 유진, 이율, 신용, 정기, 현재 …)은 넣지 않는다. 예외어 안에 든 이름은 지워지기 때문이다.
